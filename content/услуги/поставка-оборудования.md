# Поставка оборудования и ПО

ITSS является официальным представителем ведущих мировых производителей компьютерной техники и программного обеспечения в Казахстане.

## Поставляемое оборудование

- **Hewlett-Packard** — компьютеры, ноутбуки, серверное оборудование, принтеры
- **D-Link** — сетевое оборудование, коммутаторы, маршрутизаторы
- Расходные материалы для оргтехники

## Лицензионное программное обеспечение

- **Microsoft** — Windows, Office, Server
- **ESET** — антивирусные решения для бизнеса
- **Symantec** — защита корпоративных сетей
- **1С Предприятие** — настройка и сопровождение, в т.ч. с удалённым доступом через интернет

## Серверное программное обеспечение

Настройка и сопровождение серверного ПО на базе:
- MS Windows Server 2003 / 2008 / 2012
- FreeBSD (UNIX)

## Программное обеспечение для контроля сети

- Контроль доступа к сети интернет
- Корпоративная электронная почта
- Серверы баз данных
