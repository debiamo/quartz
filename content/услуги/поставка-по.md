# Поставка лицензионного программного обеспечения

ITSS поставляет лицензионное ПО ведущих мировых производителей с официальными сертификатами и гарантией.

## Операционные системы

- Microsoft Windows XP / 7 / 8 / 10
- Microsoft Windows Server 2003 / 2008 / 2012
- FreeBSD (UNIX)

## Офисные приложения

- Microsoft Office (все версии)
- Пакеты для совместной работы

## Антивирусная защита

- **ESET NOD32** — для рабочих станций и серверов
- **Symantec** — корпоративные решения

## Специализированное ПО

- **1С Предприятие** — поставка, настройка и сопровождение с возможностью удалённого доступа через интернет
- ПО для контроля доступа к сети
- Корпоративная электронная почта

> Полный список поддерживаемого программного обеспечения прилагается к договору.
